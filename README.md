# Boaz 360 — Site Institucional

Site oficial da **Boaz Soluções Tecnológicas e Empresariais** em [boaz360.com](https://boaz360.com).

## Tecnologia

Site estático em HTML5 + CSS3 + JavaScript puro. Sem dependências de build.

## Estrutura

```
boaz360/
├── index.html      # Página principal
├── styles.css      # Design system completo
├── script.js       # Interatividade e animações
└── logo-boaz.png   # Logo oficial
```

## Seções

- **Hero** — Landing com animação orbital e CTAs
- **Sobre** — Missão, Visão e Valores
- **Serviços** — Portfólio de serviços
- **Portal de Sistemas** — Acesso rápido a todos os sistemas gerenciados
- **Contato** — Formulário + WhatsApp
